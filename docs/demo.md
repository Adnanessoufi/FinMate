# FinMate walkthrough

Run `npm run dev` and open http://127.0.0.1:5187. Use example data for the walkthrough.

1. Enter starting balances and review the student plan.
2. Open Tuition and upload the sample invoice from `samples/`.
3. Check the extracted recipient, account, amount and deadline.
4. Open the tuition workflow. Choose CNY first and allow GBP as a backup if needed.
5. Build the plan and compare the fee, arrival date and protected euro reserve.
6. Prepare the exact payment. Set a payment PIN before approving it.
7. Inspect the receipt and audit in Activity.
8. Ask the assistant about a purchase, or try an income-delay scenario in Money Plan.

Sandbox studio can move the deadline to tomorrow, change a simulated rate or expire a quote. Old plans must be reviewed again after those changes.

All money is simulated. Preparing a plan does not approve it. The invoice check does not authenticate the university.
